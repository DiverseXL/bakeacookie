## What is bake?

**bake** is a CLI developer tool for Cookie Chain — a fast, cheap, Solana-compatible SVM blockchain. It's positioned as "the Vercel CLI for SVM": one-command build → deploy → verify → rollback, with every deploy recorded permanently on-chain via a small Anchor program called the **Recipe Book**.

```bash
npm install -g bakeacookie
bake --help
```

## Who is bake for?

- **Cookie Chain developers** who want a fast, zero-friction deploy experience without wrestling raw `solana deploy` flags
- **Teams** who need a permanent on-chain deploy history and verifiable build hashes for compliance and incident response
- **AI agents & agent builders** using `bake agent init` to scaffold agent projects pre-configured with safe, read-only MCP tooling (`bake mcp`)
- **Security-conscious developers** who want automated static analysis and audit-gated deploys via Radar

## 30-second pitch

Cookie Chain's economics make things possible that are impractical anywhere else — like a rollback that costs cents, or a permanent, on-chain, queryable ledger of every deploy you've ever made. bake closes the tooling gap that the ecosystem's own roadmap lists as future work.

## What makes bake different?

| Feature | bake | Raw Solana CLI |
|---------|------|----------------|
| On-chain deploy history | ✅ Recipe Book | ❌ |
| One-command rollback | ✅ `bake rollback` | ❌ Manual re-deploy |
| Cryptographic proof | ✅ `bake prove` | ❌ |
| Local disposable workspaces | ✅ `bake session` | ❌ Manual test validator |
| Agent scaffolding & MCP | ✅ `bake agent init` & `bake mcp` | ❌ |
| Windows support | ✅ Auto-WSL relay | ❌ |
| Security audit gate | ✅ `bake deploy --require-audit` | ❌ |
