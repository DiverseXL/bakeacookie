## Key milestones

### v0.4.0 — Sessions & Agent Scaffolding

- `bake agent init <name>` — scaffold AI agent project with pre-wired MCP configurations and safe read-only policy
- `bake session (open|status|deploy|close)` — disposable local development workspaces with ephemeral keypairs and automatic validator isolation

### v0.3.1 — bake dashboard

- `bake dashboard [address]` — open the companion web dashboard in your default browser
- Deploy success output now includes a dashboard deep link
- `BAKE_DASHBOARD_URL` env var for custom dashboard URLs

### v0.1.0 — Initial release

- `bake deploy` — build, deploy, hash, register
- `bake rollback` — revert to previous deploy
- `bake prove` — verify on-chain bytecode
- `bake logs` — view program logs
- `bake stats` — program activity metrics
- `bake fork` — clone program into local validator
- `bake mcp` — MCP server for AI agents
- `bake audit` — Radar integration
- Recipe Book program deployed to Cookie Chain mainnet
- Windows/WSL auto-relay
- [bakeacookie dashboard](https://bakeacookie.vercel.app)
