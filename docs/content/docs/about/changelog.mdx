## Key milestones

### v0.1.0 — Initial release

- `bake deploy` — build, deploy, hash, register
- `bake rollback` — revert to previous deploy
- `bake prove` — verify on-chain bytecode
- `bake logs` — view program logs
- `bake stats` — program activity metrics
- `bake fork` — clone program into local validator
- `bake mcp` — MCP server for AI agents
- `bake audit` — Radar integration
- Recipe Book program deployed to Cookie Chain mainnet
- Windows/WSL auto-relay
- [bakeacookie dashboard](https://bakeacookie.dev)
