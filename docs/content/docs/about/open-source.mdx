## Contributing

Issues and PRs welcome. Read [AGENTS.md](https://github.com/DiverseXL/bake/blob/master/AGENTS.md) first if you're using an AI coding agent to contribute — it documents hard-won toolchain constraints that are easy to accidentally re-break.

## Hackathon

bake was built for the Superteam Earn "Create an app on Cookie Chain" hackathon listing.

### Compliance requirements

- ✅ Built on Cookie Chain (SVM)
- ✅ Source code open source
- ✅ Published to npm
- ✅ Recipe Book deployed to Cookie Chain mainnet
