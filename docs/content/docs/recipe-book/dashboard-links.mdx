## Program page

After `bake deploy`, the CLI prints a deep link to the dashboard:

```
https://bakeacookie.vercel.app/program/<address>
```

This shows:
- Program address and metadata
- Timeline of Recipe Book entries
- Deploy vs rollback badges
- Live status strip (bytecode verification)
- Copy-paste `bake` commands per entry

## Dashboard features

The [bakeacookie dashboard](https://bakeacookie.vercel.app) is a read-only explorer:
- No login required to view anything
- Optional wallet connect for "My recipes" filter
- Never signs or sends transactions
- Public on-chain data only

## Integration

The CLI automatically prints dashboard links after successful deploys. You can also open the dashboard directly:

```bash
bake dashboard                            # opens the homepage
bake dashboard <programId>                # opens /program/<programId>
bake dashboard --ci <programId>           # prints URL instead of opening browser
```

See the [Dashboard guide](/docs/guides/dashboard) for full details.
