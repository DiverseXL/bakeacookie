## What is the Recipe Book?

The Recipe Book is a small Anchor program deployed on Cookie Chain that records every `bake deploy`. It's a permanent, public, on-chain ledger of deploy history.

**Program ID:** `56Vj61zFW4hHV6wdjnisrHtVwWDqyjixjpBgnoRJvzxL`

## Why it exists

Cookie Chain's economics make permanent on-chain history practical:
- Deploy history costs almost nothing to store
- Rollbacks cost cents
- Verification is instant

The Recipe Book turns "what did I deploy and when?" from a database question into a blockchain query.

## What it records

Every entry includes:
- **Repository** — git remote URL or short name
- **Commit** — git commit SHA
- **Build hash** — SHA-256 of the compiled binary
- **Buffer** — the buffer account used during deploy
- **Deployer** — wallet address that deployed
- **Timestamp** — unix timestamp of the deploy

## How it works

```
bake deploy
    ↓
anchor build --arch v0 --tools-version v1.57
    ↓
solana deploy
    ↓
SHA-256(compiled.so)
    ↓
Recipe Book: register_deploy(repo, commit, buildHash, buffer)
```

## Dashboard

The [bakeacookie dashboard](https://bakeacookie.dev) visualizes Recipe Book data:
- `/program/<address>` — timeline of deploy entries
- `/wallet/<address>` — programs a wallet has deployed
